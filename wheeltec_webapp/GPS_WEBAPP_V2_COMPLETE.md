## 🚀 使用指南

### 访问地址
```
http://192.168.100.5:8080/v2
```

### 使用流程

#### 1. 首页操作
1. 查看底部状态芯片区域的 GPS 状态
2. 点击 **🏠 室内模式** 按钮切换到 **🌍 户外模式**
3. 提示："已切换到户外模式 🌍"

#### 2. 户外建图
1. 确认已切换到户外模式
2. 点击 **建图** 按钮
3. 系统启动 `outdoor_mapping.launch.py`
4. 左侧显示：
   - 实时画面（顶部）
   - GPS 地图（下方）- 显示实时位置
5. 右侧：3D 点云视图
6. 遥控车建图

#### 3. 户外导航
1. 确认已切换到户外模式
2. 选择地图后点击 **导航** 按钮
3. 系统启动 `outdoor_navigation.launch.py`
4. 左侧显示：
   - 实时画面（顶部）
   - GPS 地图（下方）- 显示实时位置和导航路径
5. 中间：2D 雷达地图
6. 右侧：操作按钮（不被遮挡）

#### 4. 切换回室内模式
1. 返回首页
2. 点击 **🌍 户外模式** 按钮切换回 **🏠 室内模式**
3. 启动建图/导航将使用室内功能包

## 🔍 技术细节

### GPS 数据流
```
RTK 模块
  ↓ /gps/fix (NavSatFix)
后端订阅
  ↓ 2Hz 推送
前端接收
  ↓ WGS84 → GCJ02 转换
高德地图显示
```

### 坐标转换精度
- 转换误差：< 10米（符合 GCJ02 规范）
- 适用范围：中国大陆地区
- 转换算法：基于 Krasovsky 1940 椭球体

### 室内/户外模式对比

| 功能 | 室内模式 | 户外模式 |
|------|----------|----------|
| 功能包 | wheeltec_fastlio | wheeltec_outdoor_nav |
| 定位传感器 | 雷达里程计 | 雷达 + GPS |
| GPS 显示 | 不显示 | 显示地图窗口 |
| 建图 launch | mapping.launch.py | outdoor_mapping.launch.py |
| 导航 launch | navigation.launch.py | outdoor_navigation.launch.py |
| 定位守卫 | 无 | GPS-AMCL 双重定位 |

## 🐛 故障排查

### GPS 地图显示偏移
**原因**：坐标转换未生效

**检查**：
```bash
# 在浏览器控制台查看
console.log(gps.lat, gps.lon);  // WGS84 原始坐标
console.log(gps.gcjLat, gps.gcjLon);  // GCJ02 转换后坐标
```

**解决**：刷新页面，确保转换函数已加载

### 切换模式后仍使用旧功能包
**原因**：已启动的任务不会自动切换

**解决**：
1. 先停止当前任务
2. 切换模式
3. 重新启动任务

### GPS 地图不显示
**原因**：
1. 未切换到户外模式
2. GPS 无信号
3. 网络无法访问高德地图 API

**检查**：
```bash
# 检查 GPS 数据
ros2 topic echo /gps/fix --once

# 检查网络
ping webapi.amap.com
```

### 地图位置遮挡操作按钮
**原因**：CSS 未正确应用

**检查**：浏览器控制台查看 `#gpsMap` 的 CSS 属性
```css
left: 14px;  /* 应该是左侧，不是 right */
top: 360px;  /* 在画面下方 */
```
