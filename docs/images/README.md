# 展示图片目录

根目录 README 引用的截图。

## v2 控制台（当前在用，`/v2`）

| 文件名 | 内容 |
|--------|------|
| `v2-home.jpg` | 控制台首页：状态卡片 + 四个功能入口 |
| `v2-mapping.jpg` | 建图页 3D 点云视图（含实测地面芯片、相机画面、摇杆） |
| `v2-navigation.jpg` | 导航页 web-rviz（地图/激光/路径/代价地图分层） |
| `v2-waypoints.jpg` | 多点巡航 |
| `v2-map-editor.jpg` | 地图编辑器 |
| `v2-map-library.jpg` | 地图库 |
| `v2-settings.jpg` | 设置（语音 / 热点 / 遥控速度） |
| `hardware.jpg` | 小车实物（MID360s + 主控 + 相机） |
